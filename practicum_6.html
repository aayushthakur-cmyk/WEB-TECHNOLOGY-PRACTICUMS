CSS Positioning Techniques in a Pharmaceutical Company Webpage

Static Relative Absolute Fixed Sticky

1. position: static

Default positioning. Elements follow the normal document flow, and top, left, right and bottom have no effect. Example: the department boxes below stack in order.

Research Department
Manufacturing Department
Quality Control Department

2. position: relative

The element is moved relative to its own normal position, and its original space is still kept. Example: the middle box is shifted from where it would normally be.

Tablets Line
Capsules Line (shifted 30px down and 40px right)
Syrups Line

3. position: absolute

The element is removed from the normal flow and placed relative to its nearest positioned parent. Example: the labels sit on the corners of each product card.

4. position: fixed

The element is placed relative to the browser window and stays in the same place while the page scrolls. Example: the "Helpline" button at the bottom-right corner of the screen always stays visible.

Scroll the page up and down to see that the button does not move.

5. position: sticky

The element scrolls normally until it reaches a set position, then sticks there. Example: the table heading below stays visible while the batch records scroll past it.
